<h1 align="center">Front-End for the JWT with Authenticator Apps</h1>
<h3>This project was made with Next.js 16v (App router)</h3>
<h1>About</h1>
<h3>This project was made to use JWT authenticator app Back-End <a href="https://github.com/ALAN-MS-SU/Authenticator-JWT/">Respository</a>.</h3>
<h1>How to start</h1>
<h3>Git clone</h3>
<pre><code>https://github.com/ALAN-MS-SU/Authenticator-JWT-Front.git</code></pre>
<h2>Create the .env file and fill in all environment variables</h2>
<pre><code>NEXT_PUBLIC_API_URL=""
NEXT_PUBLIC_TOKEN_NAME=""</code></pre>
<h3>To start as dev</h3>
<h3>It's necessary to have <a href="https://nodejs.org/pt">Node.js</a> and <a href="https://classic.yarnpkg.com/lang/en/docs/install">Yarn</a> installed on your computer</h3>
<pre><code>yarn install</code></pre>
<pre><code>yarn dev</code></pre>
